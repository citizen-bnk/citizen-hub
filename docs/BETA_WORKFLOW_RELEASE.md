# Citizen beta workflow release — 13 October 2026

The Hub now exposes the source-backed licensing register, independent internal verification, named time-limited evidence releases and private reviewer findings/remediation/retesting. Board members may review governance evidence; administrators and back office maintain readiness. Reviewers do not change corporate records or receive the unrestricted risk register.

Finance records budget plans and recorded actuals, without transferring money or asserting settlement. Risk records ownership, likelihood, impact, mitigation, review dates and Drive evidence. Closing either register requires an independent administrator and source evidence. Their history is retained. People shows confirmed appointments to staff/back office; administrators manage draft/conflicting appointments through the existing appointment workflow. This is not payroll, a treasury settlement engine or regulatory certification.

New banking registrations use the shared Citizen identity provider and the role-compartment profile, followed by explicit pre-licensing enrollment. Banking and app registration retain the common optional demo selector. Enrollment cannot reactivate an administrator-revoked customer role. Existing identity, investment and application links are preserved.

The Drive connection setup is super-admin-only in live scope, bound to the initiating person and a short-lived OAuth state. It checks the configured Drive owner, creates owner-only live/demo document and recruitment folders under Citizen Digital, and stores only an encrypted refresh credential and folder identifiers. Documents stay in Drive. GOOGLE_DRIVE_CLIENT_ID and GOOGLE_DRIVE_CLIENT_SECRET must be set from a dedicated Web OAuth client with callback https://hub.citizenbank.co.ls/api/integrations/drive/callback. No Codex connector credential is exported. Existing environment-based connections remain supported. Authorization and an actual upload/share/sign/restore test are required before claiming Drive operational.

Application Resend configuration is still required for investor email. Google Form synchronization already uses the same Drive connection and the existing scheduled import, keeping changed/unreconciled submissions pending. Source records, holdings, appointments and 1,117 licensing items are not automatically approved by publication.

Verification: 48 Hub tests passed; Core 47 tests passed with 12 database-dependent tests skipped; two provider transport tests passed. All four builds/typechecks passed. Disposable workflow checks cover licensing evidence/history, self-approval denial, reviewer release/revocation, finding remediation/retest, budget/risk permissions, independent closure and linked enrollment/revocation. Production verification is recorded separately after the exact releases are ready.
